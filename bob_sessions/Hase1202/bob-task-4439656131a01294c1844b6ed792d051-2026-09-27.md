function updateTarget(p: Particle, A: number, B: number) {
  const st = Math.sin(p.theta), ct = Math.cos(p.theta);
  const sp = Math.sin(p.phi),   cp = Math.cos(p.phi);
  const bx = R * st * cp, by = R * st * sp, bz = R * ct;
  const cosA = Math.cos(A), sinA = Math.sin(A);

### Mouse / touch repulsion — exact port of `sphere.py`
Every frame, each particle's **current screen position is projected** (using the same `K1`/`K2`/`ASPECT` projection as the render pass) to find which character cell it occupies. That cell is compared against the live mouse/touch position:
